# 月末拾光用户操作 SOP

适用范围：当前 2.0.0 代码及本次改版功能。更新日期：2026-09-22。

用途：把本月照片整理、排版并导出为可按实际尺寸打印的 PDF，也可批量保存原图。

[打开月末拾光](https://yuemo-photo-sheet.dawwnforu.chatgpt.site) · [本次新增功能](FEATURES.md) · [返回项目首页](../README.md)

## 1. 开始前准备

- 建议在电脑浏览器操作，准备 JPG、PNG 或 WebP 照片。其他格式请先转换。
- 确认打印纸张规格，以及照片贴进本子后希望达到的宽高；尺寸单位为毫米。
- 原始照片请自行保留。刷新或关闭页面会清空本次照片与排版界面；“已保存照片索引”不代表云端备份，也不能恢复原图或整套排版。
- 原图不上传；文件名、照片指纹、拍摄时间、GPS、尺寸和裁剪等编辑参数会发送到后端保存。介意位置信息时，请先在本机移除照片 GPS 再导入。

## 2. 导入与查重

1. 点击左侧“选择或拖入照片”，或把照片拖入导入区域，可一次多选。
2. 等待导入完成，检查照片数量。大批高像素照片可分批导入。
3. 默认不允许重复图片。需要同一张照片打印多份时，优先调整该照片的“份数”；只有需要把同图分别编辑时，才开启“是否允许图片重复”。
4. 点击右上角“重复检查”。完全相同的图片可清理多余项；“疑似重复”应先核对缩略图，再决定是否清理。清理保留每组第一张的编辑设置和打印份数，可撤销。
5. 找不到某张照片时，在左侧按图片名称搜索，点击结果定位；可用 Enter / Shift+Enter 切换结果。

完成标准：需要的照片均已导入，重复图片已核对，份数符合打印需求。

## 3. 设置照片与纸张尺寸

1. 设置打印纸张及纵向／横向，支持 A3、A4、A5、A6、B5、Letter、5 寸和 6 寸照片纸。
2. 设置页边距、照片间隙；不确定纸张大小时，打开左下角“不清楚真实纸张大小？”查看参照。
3. 在图片详情输入每张照片的宽、高和份数；也可用“全部长边”预设统一调整。
4. 保持“等比例”锁定可避免拉伸；需要独立调整宽高时再解锁。
5. 在打印预览选中照片，可旋转、裁剪或拖动四角调整大小。照片尺寸变化会触发重新排版。

完成标准：宽高与份数正确，没有超出纸张可用范围的照片。

## 4. 使用本次新增排版设置

点击右上角“设置”，按需要使用下列功能。

| 需求 | 操作 | 检查结果 |
| --- | --- | --- |
| 保留照片朝向 | 勾选“不允许图片自动旋转” | 自动排版不再代为旋转；仍可手动旋转 |
| 照片排列成整齐的栏 | 勾选“开启严格分栏”，选择每页 1–4 栏 | 各栏居中、按行对齐 |
| 按时间或地点排列 | 勾选“开启排序筛选”，回到左侧“排序分类”选择模式 | 左侧顺序、打印预览与 PDF 按所选规则排列 |

严格分栏不会为塞入栏位而自动缩小照片。出现超宽提示时，调小照片、减少栏数或调整纸张和边距，再检查预览。

### 排序分类如何选

- **导入顺序**：保留导入次序。
- **拍摄时间升序／降序**：使用照片中记录的拍摄时间；没有拍摄时间的照片排在后面，不拿文件修改时间替代。
- **按拍摄地点分类**：按照片自带 GPS 和“同地点范围”归组，不是按城市名识别，也不会识别画面中的地点。
- **智能：同日相近时间、同地点优先**：把同一天、时间窗口内的同地点照片放到一起，例如符合条件的 A→B→A 可排为 A→A→B。

“同地点范围”可选 30、100、300、1000 米，默认 100 米；“相近时间”可选 1、3、6、12 小时，默认 3 小时。时间窗口用于智能分类，归组以组内首张照片为参照。缺失元数据时不会猜测地点或拍摄时间；截图和转发照片可能不带这些信息。

完成标准：逐页查看顺序、朝向与分栏，确认符合这次手帐的叙事顺序。

## 5. 在本子上试摆

1. 在单张照片详情点击“在我的本子上预览”；多张照片可先勾选，再点击“在我的本子上预览所选”。
2. 选择 A5、A6、A4 预设，或输入实际测量的本子单页宽高，设置横竖方向。
3. 拖动照片调整摆放，可叠放、旋转或用方向键微调。出现红框表示超出本子页面。
4. 照片与本子按相同物理比例显示，屏幕上不是实物 1:1 大小。
5. 在本子预览修改照片尺寸，会同步影响打印排版与 PDF；本子上的摆放位置与角度仅用于试摆，不会把打印 PDF 变成本子布局。

完成标准：照片大小适合本子，返回主界面后再次核对打印排版。

## 6. 批量选择与导出

勾选左侧照片方框，或按住 Ctrl（Mac 为 ⌘）点击照片多选。先确认“已选 N 张”，可用“全选”或“取消选择”。

| 按钮 | 导出内容 | 注意事项 |
| --- | --- | --- |
| 导出所选 PDF | 只对选中照片重新排版，包含设定的打印份数 | 页数和位置可能与全量预览不同 |
| 下载所选原图 ZIP | 选中照片的原始文件 | 不应用裁剪、缩放或打印份数，保留原始拍摄信息 |
| 另存为文件夹 | 在选定位置中新建文件夹保存原图 | 浏览器不支持时自动改为下载 ZIP |
| 分享所选原图 | 调用系统分享界面 | 不支持时改为下载 ZIP 后自行发送 |
| 导出打印 PDF | 全部照片的打印排版 | 导出前应消除尺寸超限提示 |

需要按日期整理原图时，先勾选“保存原图时按拍摄日期分文件夹”；无拍摄时间的照片放进“日期未知”。重名文件会添加编号，避免互相覆盖。保存中途失败时，文件夹可能已包含部分照片，应检查后再重试。

## 7. 打印与验收

1. 点击“导出打印 PDF”或“导出所选 PDF”，等待生成完成，过程中不要刷新或关闭页面。
2. 打开下载的 PDF，检查页数、照片数量、裁剪内容、朝向及有无漏图。
3. 打印时选择与排版一致的纸张，缩放选择 **“实际大小 / 100%”**，关闭“适合页面”。
4. 首次使用打印设备时先试印一页，用尺测量一张照片的宽高，确认后再打印剩余页面。

PDF 按 300 DPI 生成；低清原图不会因此增加画面细节。

## 8. 收尾与索引保存

- 把需要的 PDF 和原图保存到自己的文件夹，并实际打开确认文件可用。
- “已保存 N 条照片索引”仅表示元数据写入成功，不表示照片或完整排版已备份。
- 出现“照片索引未保存”时仍可本机排版和导出；检查网络，下一次编辑会重试。先导出所需结果，不要靠刷新尝试恢复。
- 公共电脑使用完成后点击“清空”，等待索引显示保存 0 条，再关闭页面并删除下载文件。如果索引保存失败，不能把关闭页面当作服务器端清除成功。

## 常见问题

| 情况 | 处理方式 |
| --- | --- |
| PDF 导出被阻止 | 查看超限提示，缩小照片、减少栏数或调整纸张／边距 |
| 时间或地点排序不符合预期 | 检查原图是否带 EXIF 拍摄时间和 GPS；尝试导入相机原始文件 |
| 批量按钮不能点击 | 先勾选至少一张照片，等待正在执行的导出结束 |
| 本子预览与 PDF 摆放不同 | 本子预览用于模拟粘贴；PDF 按打印纸张重新排版，仅照片尺寸同步 |
| 刷新后照片消失 | 重新导入原图；当前版本不恢复先前排版 |
| 大量照片处理慢 | 等待当前操作完成，或导出后分批处理；关闭不需要的浏览器标签页 |
| 打印尺寸不对 | 核对纸张规格，关闭自动缩放，以实际大小／100% 打印 |

选中打印预览中的照片后：Delete / Backspace 删除，+ / - 微调长边，R 旋转，Ctrl / ⌘ + Z 撤销，Esc 取消选择，? 查看快捷键。输入框内编辑时不触发这些页面快捷键。

仍无法解决时，点击“问题反馈”，提供浏览器、照片数量、设置、复现步骤和预期结果；示例截图请先去除隐私内容。
