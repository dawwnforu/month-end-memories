# 月末拾光 · Month-End Memories

一款面向手帐、照片墙和纸质纪念册制作的 A4 照片智能排版工具。导入照片、按毫米设置成品尺寸，系统会自动旋转并优化照片组合，尽可能减少 A4 纸留白，最后一键导出适合打印的高分辨率 PDF。

**当前版本：`release2.0.0`**

**在线使用：<https://yuemo-photo-sheet.dawwnforu.chatgpt.site>**

**使用文档：[用户操作 SOP](docs/USER-SOP.md) · [本次改版新增功能](docs/FEATURES.md)**

![月末拾光预览](public/og-v2.png)

## 项目简介

月末拾光解决的是一个很具体的日常问题：每个月挑选值得纪念的照片，把它们彩印在 A4 纸上，剪下来贴进手帐。

传统做法需要在 Word 中逐张插入、缩放和移动图片。这个项目把过程简化为：

1. 一次导入多张照片；
2. 输入每张照片希望打印的宽度、高度和份数；
3. 自动计算更省纸的 A4 排列方式；
4. 需要时手动旋转或拖动四角微调尺寸；
5. 一键导出 300 DPI A4 PDF，直接送到打印店彩印。

## 主要功能

- 支持 JPG、PNG、WebP，可一次选择或拖入多张照片；
- 默认按解码后的完整像素和尺寸识别重复项，不依赖文件名；改名或只改变元数据的同图仍可识别。同名但画面不同的图片会保留。重新压缩、缩放或在文件中旋转后的近似图片不自动合并；
- 左侧图片详情上方支持按名称搜索，显示全部匹配位置；点击结果或使用上/下一处、Enter / Shift+Enter，在多页预览中定位并高亮；
- 重复图片悬浮面板列出文件名、图片序号、页码、页内序号和打印份数位置；被阻止导入的图片会指向已有图片；
- 可主动一键消除多余图片，每组保留第一张及其编辑设置；支持撤销，不改变用户设置的打印份数；
- 原始名称相同但像素不同的图片会列为“疑似重复”，忽略名称末尾的导出时间和复制编号；可查看缩略图并定位，核对后按组清理，不自动按名称删图。名称完全不同的相似画面尚不识别；
- 可开启“是否允许图片重复”，允许后相同图片会分别导入且不再显示重复提醒；
- 按毫米设置每张照片的打印宽度和高度；
- 锁定原始宽高比，修改一边时自动计算另一边；
- 支持同一张照片打印 1–20 份；
- 提供 50、60、70、90 mm 常用长边预设；
- 支持 A3、A4、A5、A6、B5、Letter、5 寸和 6 寸照片纸；
- 所有纸张均支持纵向和横向，预览、自动排版与 PDF 同步切换；
- 左侧底部提供纸张真实大小参考，可在全部纸张规格与中性笔、银行卡、手机、鼠标、充电器、课本、海绵、纸巾等常见物品之间切换，查看同比例图和宽高换算；
- 可设置页边距与照片间空隙；
- 自动允许照片旋转 90°，提高纸张利用率；
- 每张照片可手动顺时针旋转，每次旋转 90°；
- 点击照片后显示蓝色选中边框和四角缩放点；
- 拖动缩放时实时重新排列其他照片，并同步更新页数；
- 支持拖动裁剪框和四角控制点进行自由裁剪；
- 可解除宽高比例锁定，通过输入数值或拖动控制点进行自由尺寸缩放；
- 支持删除、毫米级缩放、旋转、撤销等键盘快捷键；
- 右侧小问号下拉显示全部快捷键；编辑数字输入框时自动停用页面快捷键；
- 实时显示照片数量、A4 页数和面积利用率；
- 自动识别无法放入当前 A4 可用区域的照片；
- 导出 300 DPI、多页 A4 PDF；
- 所有照片处理与 PDF 生成均在当前浏览器中完成。
- 右上角“设置”集中管理禁止自动旋转、严格分栏（1–4 栏）和排序分类；严格分栏保持栏中心与行对齐，不擅自缩小超宽照片；
- 开启排序后，左侧可选拍摄时间升序／降序、GPS 地点分组或智能分类。智能分类在同一天、指定时间窗口内按地点聚合 A→B→A；地点半径与时间窗口可调整，缺失信息不推测；分类顺序同步到打印预览与 PDF；
- Ctrl / ⌘ 点击或左侧复选框多选，支持批量原图 ZIP、日期文件夹、PDF、系统分享及本子预览；
- JPEG、PNG、WebP 的 EXIF 拍摄时间与 GPS 在本机读取。屏幕使用最长边 640 像素的预览图，PDF 逐张解码原图，每页完成后释放画布；
- 页面固定文字不可选取或剪切，照片区域禁止拖拽和右键复制，减少公共设备上的误操作；
- 右上角提供结构化问题反馈入口，反馈统一进入 GitHub Issues。

## 隐私说明

导入的原图通过浏览器本地对象地址读取，排版与 PDF 生成在设备本地完成，不上传原图。文件名、像素指纹、拍摄时间、GPS 坐标、尺寸及裁剪参数会写入后端 D1 数据库；不要求注册账户。页面显示索引保存状态，数据库暂不可用时仍可本机排版和导出。

页面会阻止普通的文字选择、复制、剪切以及照片拖拽和右键复制，但网页无法阻止操作系统截图、开发者工具或具有设备权限的软件。真正的隐私保证来自照片不上传服务器，而不是仅依赖界面限制。

关闭或刷新页面后，本机原图和排版界面会清空，数据库记录不会自动恢复原图。每个浏览器标签页通过保存在 sessionStorage 的随机工作区凭据隔离记录；凭据只在请求头传输，数据库只保存其哈希。清空照片后同步清空当前工作区的索引。使用公共电脑时，完成后清空照片、等待索引保存，再关闭页面并删除下载的 PDF。

## 照片数据库与大批量验证

本地开发首次运行 `npm run db:local` 应用迁移，再运行 `npm run dev`。数据库位于项目 `.wrangler/state`，不会连接远程数据库。部署时需要绑定真实 D1 为 `DB` 并应用 `drizzle/` 下的迁移；`wrangler.local.jsonc` 的占位 ID 仅供本地使用。

`photo_records` 以工作区和照片 ID 为联合主键，时间、GPS、指纹分别建立工作区内索引。毫米和经纬度使用 REAL，拍摄时间保持相机原始当地时间，不擅自转换时区。原图、预览和浏览器对象地址不入库。`PUT /api/photos` 原子保存当前工作区快照（最多 2000 条），`GET /api/photos` 支持时间区间、时间排序和每页 500 条分页；两者都要求工作区 Bearer 凭据。

- `npm test`：构建、EXIF/GPS、A→B→A 分类、320 张严格分栏及现有功能回归。
- `npm run typecheck`：生成本地 Cloudflare 类型并检查全项目 TypeScript；生成的类型文件不提交。
- `npm run test:database`：开发服务运行时验证 320 条记录、精度、日期查询、工作区隔离和无效写入保护；仅清理测试自身工作区。
- `npm run test:photos`：在 `outputs/load-photos` 生成 320 张不同的 3072×2048 JPEG，带拍摄时间和 GPS，供浏览器负载测试。实测完成全部导入、索引保存、智能分类和 32 页 300 DPI PDF 导出。测试图为合成图片，更高像素或复杂压缩的实际照片耗时可能不同。

## 普通用户电脑要求

在线使用不需要安装 Node.js、Git 或其他开发工具。

| 项目 | 最低要求 | 推荐配置 |
| --- | --- | --- |
| 操作系统 | Windows 10、macOS 12 或常见 Linux 桌面系统 | 仍在安全支持期内的系统版本 |
| 浏览器 | 支持 File API、Canvas、Blob 和 ES Modules 的现代浏览器 | 最新稳定版 Chrome、Edge、Firefox 或 Safari |
| 内存 | 4 GB | 8 GB 或以上；大量高像素照片建议 16 GB |
| 屏幕 | 1280 × 720 | 1920 × 1080 或以上 |
| 网络 | 首次打开网页需要网络 | 稳定宽带或 Wi-Fi |
| 打印 | 可打开 PDF 的 A4 打印环境 | 彩色打印机或打印店，选择 100% 实际大小 |

手机和平板可以打开网页，但照片精细缩放、批量排版和 PDF 打印更适合在电脑上完成。

## 使用方法

1. 打开[在线版本](https://yuemo-photo-sheet.dawwnforu.chatgpt.site)。
2. 按需开启“是否允许图片重复”，再点击“选择或拖入照片”导入本月照片；默认不允许重复。
3. 在左侧为每张照片设置宽、高和份数。
4. 在右侧 A4 预览中点击照片：
   - 点击右上角旋转按钮可顺时针旋转 90°；
   - 点击剪刀按钮可拖动选框自由裁剪；
   - 拖动四角蓝色圆点可自由缩放；
   - 在左侧解除“等比例”锁定后，可分别调整宽和高；
   - 缩放过程中其他照片会实时重新排列。
5. 点击预览标题下方的小问号可下拉查看全部键盘操作。
6. 若不确定纸张实物大小，点击左下角“不清楚真实纸张大小？”查看同比例参考图。
7. 确认纸张页数与利用率。
8. 点击“导出打印 PDF”。
9. 打印时选择与页面设置一致的纸张，并选择 **实际大小或 100%**，不要选择“适合页面”或自动缩放。

## 快捷键

先在 A4 预览中点击并选中一张照片。

| 快捷键 | 操作 |
| --- | --- |
| `Delete` / `Backspace` | 删除选中照片 |
| `+` | 选中照片长边增加 1 mm |
| `-` | 选中照片长边减少 1 mm |
| `R` | 选中照片顺时针旋转 90° |
| `Ctrl + Z` / `⌘ + Z` | 撤销上一步 |
| `Esc` | 取消照片选择 |
| `?` | 打开或关闭快捷键下拉提示 |

当光标位于宽、高、份数、页边距或缝隙等输入框中时，以上页面快捷键会自动停用，避免打字时误删或误调照片。

## 环境配置

当前版本不需要第三方 API Key 或图片存储；照片索引保存需要 Cloudflare D1 的 `DB` 绑定与数据库迁移。本地先运行 `npm run db:local`，无需为此创建 `.env` 文件。数据库暂不可用时，本机排版和 PDF 导出仍可使用。

| 配置项 | 是否必需 | 说明 |
| --- | --- | --- |
| 环境变量 | 否 | 当前版本没有必需的运行时密钥 |
| 数据库 | 索引保存需要 | D1 绑定为 `DB`，保存照片元数据与编辑参数，不保存原图；部署时应用 `drizzle/` 迁移 |
| 对象存储 | 否 | 图片在浏览器本地处理 |
| 登录系统 | 否 | 公开网页可直接使用 |
| PDF 服务 | 否 | 使用浏览器端 jsPDF 生成 |

仓库中的 `.openai/hosting.json` 用于现有 Sites 部署。它不包含照片、账号密码或 API 密钥。部署到其他平台时，可以根据目标平台调整构建入口和静态资源配置。

## 已知说明

- 超高像素照片会占用较多浏览器内存，建议分批处理；
- 照片尺寸、页边距和间隙都以毫米计算；
- 面积利用率用于辅助判断，不代表所有剩余空白都能容纳下一张照片；
- 打印店必须关闭“适合页面”，否则实际成品尺寸会发生变化；
- 浏览器刷新后不会保留当前照片与排版状态。
